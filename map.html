Map Intro & Features

Island Exploration Guide

A full-featured interactive Heartopia map built on Leaflet.js, with 100+ accurate markers across 9 categories: NPCs, resources, fishing spots, shops, insects, birds, animals, landmarks and bus stops. Whether you're a beginner running routes or a completionist filling every encyclopedia, this one map has the whole island covered.

🔍

Live Search

Type to instantly match every marker name, description and category — find anything in a flash.

🏷️

Category Filters

Toggle 9 categories independently; resources also filter by berry, fruit, mushroom, ore and wood subtypes.

🚶

Run Route

Built-in daily route: Home → Meadow Lake → Central Plaza → Fishing Village → Home. One tap for efficient gathering.

📌

Custom Markers

Right-click anywhere to add personal markers — 20 icons to choose from, saved to your browser's local storage.
